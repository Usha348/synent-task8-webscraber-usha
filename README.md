# Task 8 - Web Scraper

## Objective
Create a simple web scraper using Python.

## Features
- Connects to a website
- Extracts quotes and author names
- Displays scraped data in terminal

## Technologies Used
- Python
- requests
- BeautifulSoup4

## Files
- web_scraper.py

## How to Run

1. Install libraries

pip install requests

pip install beautifulsoup4

2. Run the program

python web_scraper.py

## Output Example

Quote: “Life is beautiful”
Author: Albert Einstein

## Learning Outcome
Learned:
- Web scraping
- HTML parsing
- Using requests library
- Using BeautifulSoup
- Extracting website data
